# java-lotto-precourse

| 기능 | 세부사항 | 예외처리 |
|------|----------|----------|
| 로또 구입 금액 입력받음 | - 1,000원 단위<br>- 구입 금액에 해당하는 만큼 로또 발행 | - 1,000원 단위인지(나누어 떨어지지 않으면 예외처리)<br>- 0원이면<br>- 숫자만 입력했는지 |  |
| 발행한 로또 수량 출력 |  |
| 당첨 번호 입력받음 | - 번호는 쉼표로 구분<br>- 중복되지 않는 6개의 숫자 | - 형식에 맞는지(regex)<br>- 숫자만 입력했는지<br>- 숫자 범위(1~45)에 해당되는지<br>- 중복되지 않는 6개인지 |  |
| 보너스 번호 입력받음 |  | - 숫자 하나만 입력했는지<br>- 숫자 범위(1~45)에 해당되는지<br>- 중복되지 않는 6개인지 | 
| 발행한 로또 번호 출력 | - 오름차순으로 정렬 |  |
| 당첨 내역 출력 |  |
| 수익률 출력 | - 당첨 기준과 금액 계산<br>- 수익률은 소수점 둘째 자리에서 반올림 |  |
| 예외 상황 시 에러 문구 출력 |  | - 에러 문구는 "[ERROR]"로 시작 |  |
